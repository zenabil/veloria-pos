Comment ça marche

Quatre étapes, zéro friction.

  1. Activation en caisse : téléphone + PIN + QR.
  2. Connexion : aucun compte web.
  3. Synchronisation : la caisse pousse les clichés.
  4. Consultation : même hors-ligne. Révocable.
